# 无线组网与传感器配置

## 已选硬件与开发实现

主控候选 ESP32-C3-WROOM-02U-N4 集成 2.4 GHz Wi-Fi 与 Bluetooth LE，并使用外接天线。已设计主板位置，机械装配包含柔性天线和同轴线包络；实际 RF 匹配、兼容认证和实机通信尚未验证。ESP-IDF 开发固件已有真实 ESP32-C3 构建记录，见 ../firmware/README.md。

官方规格：
https://documentation.espressif.com/esp32-c3-wroom-02_datasheet_en.html
https://www.espressif.com/en/module/esp32-c3-wroom-02u-en

建议 Wi-Fi 承担正常数据与受控命令链路，BLE 用于有身份校验的近距离配网和维护。单芯片同时具备能力不等于已经实现应用协议，也不等于可使用任意校园认证网络。

## 推荐拓扑

插座以 Wi-Fi Station 连接校园 IoT 专用 AP；经校园局域网连接楼宇边缘服务，再由边缘服务连接云平台。AP 提供无线接入，边缘服务器负责计算、数据与策略；两者功能不同，可根据部署条件分设或集成。

第一阶段不采用插座间多跳 Mesh。部署前核实 AP 覆盖、设备容量、2.4 GHz 干扰、设备认证、VLAN、IP 分配、DNS/NTP、运维权限与防火墙规则。上述为部署设计事项，本项目没有配置实际校园网络。

开发固件已实现 MQTT 双向 TLS 客户端、精确设备主题、BLE Security2 配网代码、重连、受认证时间挑战及持久命令序号。边缘服务使用严格合同、SQLite 保存遥测及平台 outbox，再返回持久收据。上述尚未在真实网络与硬件上验证；未部署 broker，也未提供证书生命周期服务、签名升级或 OTA。主机测试中的认证布尔输入不能代替真实 mTLS 通道；生产仍依赖逐设备 ACL。

每台设备应具有唯一 ID、绑定位置、负载能力档案、计量时间与质量标记。消息应包含版本、序列和过期时间，并处理重复、重连和超时。设备数与上报频率须据试点实测确定，不能宣称未经验证的并发规模。

公网中断时，局域网中已有授权策略可继续；局域网中断时采用端侧既定策略。仅补传历史遥测，不补执行过期动作。不能默认断网、识别不确定或测量变旧就切断所有负载；独立故障保护另行处理。

## 传感器与状态检测

| 项目 | 设计位置与用途 | 当前完成程度 |
|---|---|---|
| 电压、电流与电能计量 | 计量前端提供功率与累计电量，并按器件能力提供其他电参数 | ATM90E26、隔离供电/SPI 与真实计量前端参考 PCB 已形成，正在整合主板；无每设备标定或精度实测 |
| 板上温度 | TMP102，监测其安装处局部温度 | 原理图、布局与包络已包含；无标定或温升实测 |
| 关键触点温度 | 远置 TMP302B 温度开关拾取指定接触区热状态 | 独立热保护方案已设计；它输出阈值状态而非连续热点温度，板温不能替代触点温度 |
| 独立温度切断 | 温度开关与硬件保持断开链、串联温度保险候选 | 已有电路与器件选型，正在整合热耦合结构；动作温度、热延迟与保护协调未验证 |
| 继电器实际执行核验 | 输出电压、电流或独立反馈等方案，区别命令与真实供电 | ACPL-K376 反馈参考电路、PCB 与 GPIO3 双边沿资格判定已实现；无真实故障注入 |
| 房间温湿度 | 独立房间节点，服务舒适度与空调策略 | 系统接口规划，不装入当前每个插座 |
| 房间占用、门窗 | 共用房间节点，按隐私和需求选择 | 系统接口规划，无实际传感器或人员识别实现 |

不建议为了数量把光照、空气质量、占用等全部塞入插座。墙角或家具后位置、自身发热与遮挡会影响代表性。电碳估算使用电量和可追溯排放因子，不设置“碳排放传感器”来冒充核算。

## 算力边界

端侧负责采样协调、特征提取、规则、约束执行及经资源预算的小规模推理；楼宇侧承担多设备协调；云端承担训练与更广范围预测优化。当前不包含已训练负载识别模型或已运行的校园调度系统。启用任何学习策略前，应有基线、验证集、置信度阈值和未知负载保守路径。

## 校园接入前提与未实现能力

当前代码针对可配置的 Wi-Fi Station 接入；没有实现校园网页 Portal 自动登录、WPA-Enterprise/802.1X 凭据管理或插座间 Mesh。应先取得学校网络管理员批准的 IoT 接入方案，不能为了联网私自修改校园网络安全设置。设备不需要独立公网 IP，也不需要从公网开放入站控制端口；由设备主动连接授权 broker，云边转发路径再按校园策略部署。

负载档案靠受控登记与调试授权；当前没有能可靠检测所有“拔下旧电器、换上新电器”事件的硬件与算法。换负载必须重新审核档案，不能把静态档案当成自动识别结果。端侧没有训练好的负载分类模型。
