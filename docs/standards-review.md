# 接口与安全标准核对记录

核对日期：2026-09-30。

## 已核实的官方标准元数据

GB 1002-2024《家用和类似用途单相插头插座 型式、基本参数和尺寸》：官方页面状态“现行”；2024-07-24 发布，2025-08-01 实施。官方链接：
https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F8C9E208891B7BB5AF1B3E64933693C2

本次已查阅官方元数据，但未取得可可靠读取的完整尺寸图和量规条款。因此不把本项目临时孔位、插脚宽厚及公差作为符合该标准的尺寸。官方元数据不能替代标准全文审查。

## 必须继续完成的工作

由专业人员依据最终产品归类确定全部适用标准与认证路径，特别是插接几何、保护门、温升、防触电、绝缘与接地、异常工况、材料与机械耐久。不能只因一项标准名称存在，便宣称整机满足全部要求。

确认匹配的合格插接组件、目标墙面插座和目标负载；用正式图纸或量规校验替换临时接口尺寸。任何插孔或插脚变更必须重新生成 CAD、工程图和渲染，并复核内部空间。

本设计不是“16A 万能插孔”，没有对10A插头或不匹配插头的适配承诺。统一硬件/软件体系与机械接口兼容性是不同层次。
