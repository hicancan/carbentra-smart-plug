# 工程发布与实物放行门槛

本文件把“数字设计完成”与“允许制造、接入真实 220V 负载”分别定义。数字发布包不能代替市电产品专业审查、实验室测试或适用的合规评定。未开展的测试必须标为待验证，不能用计算或渲染替代实测。

## 1. 本次数字交付验收

1. 设计身份一致：统一为 CARBENTRA-P16-EVT-B；原理图、PCB、机械坐标、固件引脚表、Blender 与 GLB 使用同一冻结版本。Rev A 仅作可追溯历史，不混入 B 的完成统计。
2. 文件可打开：FreeCAD 原始文件、STEP、KiCad 原理图/PCB、Blender 场景、GLB、图纸与 MP4 逐类检查。脚本、依赖版本、源文件和导出物具有校验值。
3. 电气证据明确：ERC、DRC、未连接数量、引脚网络核对、绝缘区域约束分别报告；0 DRC 不等于器件选型、载流、温升或安全合格。
4. 机械证据明确：检查有效实体、坐标、外壳/器件/引脚/导线包络干涉、插入通道、人工复位触达、天线空间。名义器件包络和未确认量规尺寸必须单列。
5. 代码证据明确：真实 ESP32-C3 构建、主机策略/协议/反馈回归、边缘单元测试记录与源摘要对应。默认禁止继电器驱动，不附任何生产密钥或虚构标定数据。
6. 展示一致：剖面、六视图、内部结构、分层爆炸图与动画来自冻结装配；标注文字不能遮挡关键部件。动画实际编码并抽帧检查，不将场景时间轴冒称视频文件。
7. 交付可用：提供中文入口说明、审阅册、工程源文件、Git 历史包和校验清单。大文件按独立用途拆包，避免用户无法下载。

## 2. 进入样机阶段前的阻断项

- 接口：按适用标准的实际量规核对插销、插孔、保护门与拔插路径。统一平台不能使不匹配插头安全兼容，不能宣称支持任何 10A/16A 接口。
- 电源与额定：工程工作窗口为标称 220V 场景的 198–242V AC；264V 只可作明确标注的部分电路计算边界，不能作为整机连续额定值。16A 是候选目标，尚不是经过验证的长期允许载流能力。
- 载流与短路：由合格硬件人员复核端子、铜箔、分流器、触点、连接导体、保险及保护接地的完整路径；不得仅凭继电器外壳印字推断空调启动适用性。
- 绝缘：根据真实污染等级、过电压类别、海拔、材料、涂覆与加工条件评审净距/爬电/绝缘系统。光耦和电源单体参数不能自动证明整机隔离。
- 热：核对最坏工况电源损耗、接触电阻、外壳热点、贴附传感器热延迟和独立断开链。热垫材料击穿数据不能直接作为整机强化绝缘证明。
- 结构工艺：候选材料、阻燃要求、卡扣/螺钉、尺寸公差、插拔寿命、墙插支撑力矩、跌落和导线固定需要制造级评审。
- 采购：检查每个器件的准确后缀、封装、额定和供应来源，以实际到货器件核对模型及焊接工艺。

以上事项未关闭时，发布状态为 FABRICATION / ENERGIZATION HOLD。此状态并不妨碍审阅数字工程和制作明确不带电的外观验证件。

## 3. 受控实物验证需要留存的证据

测试必须由具备资质/能力的人员在相应设施与防护条件下制定和执行；本仓库不提供直接市电接线操作指引。

- 电气安全与保护：接地连续性、绝缘、耐压/泄漏、异常状态、过流保护协调、触点失效与独立热保护；保存条件、设备、样品编号和原始数据。
- 计量：在可追溯参考仪器下覆盖不同电压、电流、功率因数和负载波形；记录每台实际标定系数、误差、温漂、低功耗误差与重复性。
- 空调适配：以明确型号和启动/运行边界验证供电控制、最短停启间隔、失联/掉电恢复，不推广为所有压缩机或所有空调通用。
- 反馈故障：覆盖光耦链断路、卡高/卡低、波形异常、开路中性线、背馈与焊死触点。未检出脉冲不能证明无危险电压。
- 热与耐久：最坏环境温度、长期负载、触点老化、装配偏差、温控拾取失效和保护器动作；保留热像/测点位置与完整时序。
- 无线与 EMC：真实壳体及墙面条件下的天线、配网、重连、群体并发、干扰与适用 EMC/浪涌测试。
- 软件与安全：真实 mTLS 身份和 broker ACL、证书过期、重放、时间漂移、重连竞态、NVS 异常、复位、队列拥塞及 RAM 数据丢失表现。安全启动、密钥生产和升级回滚另行设计验证。

## 4. 平台成效不能预设

- 接入平台不等于已经运行数字孪生闭环；必须验证实体设备 ID、空间位置、实时质量标记、状态映射和历史一致性。
- 有功电能与削峰、电费、排放分别评价。动态因子和固定因子不得混用，分表与总表不得重复相加。
- 节能率需要可比较基线，并控制课程、气候、占用、设备更换与终端自身耗电。未实施对照实验，不提供“已节能 X%”结论。
- 当前预测是透明基线，当前削减计划仅输出建议；没有训练结果或真实校园数据时，不宣称 AI 预测精度或自主调度效果。

## 5. 项目评审时的准确表述

可以说：“我们完成了统一终端的可追溯数字工程、开发固件与边缘参考实现，并提供实际软件测试记录；产品正在等待制造、安全与场景验证。”

不能说：“已通过 220V 安全认证”“可直接接任意空调”“已完成量产设计”“已实现并验证全校园自动节能”，除非后续确有相应证据。
