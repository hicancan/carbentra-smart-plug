# 数字设计验收基线

## 设计意图
一款统一自适应插座，通过负载能力描述对不同设备使用不同策略。云端提供预测和全局目标，边缘负责区域协同，端侧执行本地约束；本地安全限制不可被云端覆盖。

## 数字交付检查
1. 机械源文件与 STEP 可读取；主要零件独立，统一毫米坐标系；输出可核对的包络和装配清单。
2. 插孔、载流接触、后部插脚和 PCB 位置对应；未验证的标准接口尺寸明确标注。
3. PCB 源文件可用 KiCad 读取；有 BOM 和器件信息；ERC/DRC 结果逐项保留，不能伪称全通过。
4. Blender 与机械/PCB 数据映射一致；出图无缺件、错位、严重穿模、标签重叠。
5. 交付外观、六面视图、内部结构、剖切、爆炸视图和动画；导出 GLB 可解析。
6. 单一平台及策略状态模型具有可执行参考测试；ESP32-C3 开发固件必须真实交叉编译并默认禁止继电器驱动，边缘服务通过单元测试；均非经过实机验证的生产系统。
7. README 说明复现、工具版本、源文件与生成文件、验证边界及未关闭问题。
8. Git 提交、发布清单和 SHA-256 校验可追溯。

## 不能由数字交付替代的验证
实际载流和接触温升、绝缘耐压与漏电、接地连续性、浪涌/EMC、机械插拔寿命、保护动作及故障工况、无线性能、真实计量标定、空调启动及重启适配。没有证据不标为通过。
