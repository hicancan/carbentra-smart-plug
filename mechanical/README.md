# 碳镜校园 CM-S16 · 机械工程开发模型

**版本 CM-S16-EVT-A。工程开发设计，禁止按此直接制造通电样机。**

这是一个统一硬件平台：单个三孔、16 A 等级、220 VAC 设计目标，软件负载能力档案不改变插头/插座的物理兼容性。没有 10 A 插头兼容性或“万能孔”承诺。不是米家产品内部复原。六张用户参考图片仅用于观察外观类别；所有内部结构和尺寸是本项目自定义设计输入。

## 文件与打开方式

- `CarbonMirror_S16_SystemAssembly.FCStd` / `.step`：统一坐标的完整机械+KiCad板件装配（电子器件为候选包络）
- `CarbonMirror_S16_EVT_A.FCStd`：54 个独立、命名、可检查的 FreeCAD 实体与参数表
- `CarbonMirror_S16_EVT_A.step`：装配交换文件
- `step/*.step`：单件 STEP；`meshes/*.stl`：对应单件可视化网格
- `design_parameters.json`：尺寸、坐标、接口和工程边界
- `parts_manifest.json`：部件清单、材质候选、色彩、包围盒与建议爆炸位移
- `drawings/CM-S16-EVT-A_general_arrangement.pdf` / `.svg`：A3 总体尺寸与装配控制图；侧向视图是标明的名义堆叠布局，不是隐藏线投影的制造剖面
- `validation.json`：54 个机械实体的逐对 BRep 干涉审计
- `integration_validation.json`：FCStd 重载、参数编辑、PE 联通、PCB/元件包络适配审计

FreeCAD 1.0.0 已验证。通过 FreeCAD 宏面板打开 `Open_Model.FCMacro`，它设置本地参数模块搜索路径、打开源文件并应用材质色。直接打开 FCStd 可查看保存的实体；若要重算 Python 参数特征，应先将本目录加入 Python 路径并导入 `socket_features`。外部 Python 代理源码随项目提供，无插件下载。

在本机已安装环境重建：

```sh
/usr/bin/python3 mechanical/generate_model.py
/usr/bin/python3 mechanical/validate_assembly.py
/usr/bin/python3 mechanical/drawings/generate_drawing.py
```

FreeCAD 的 Parameters 表格 B1/B2/B3 驱动 Width/Height/Depth。已实测宽度 88→90→88 的原生重算。JSON 包含其余设计输入；更改后重运行生成器。尺寸系统是受约束的开发模型，任意大幅改尺寸后必须重新检查干涉和接口，不是无限适配的插座生成器。

## 坐标与结构

单位 mm。原点为后壳中心的背面 z=0；+Z 为插座正面，+Y 指向 PE 插孔。

| 项目 | 名义值 |
|---|---|
| 外壳 | 88×88×55；平面角半径14 |
| 后向插脚伸出 | 20（待标准量规替换） |
| 壁厚/背板 | 2.4 / 3 |
| 前后壳分界 | z46；前盖正面 z55 |
| PCB | 72×68×1.6；z8–9.6；元件上限 z28 |
| PCB 安装孔 | D3.2，(±31,±29) |
| 接触件绝缘载体 | 主体 z31–47；上部压紧凸台至52.6 |
| 后侧装配螺钉轴 | (±38,±24) |
| 正面按键/导光柱 | (0,-32)/(0,33) |

后壳包含 PCB 支柱和 z30–31 的侧向载体承台。载体被前盖的接触面与承台夹持，上下包络不穿过 PCB。四个后侧长螺钉连接前盖盲孔柱；螺纹、扭矩、拉拔力及防触及要求待专业设计。实际制造需要定位止口、拔模与公差链，不应直接以理想面接触替代制造间隙。

三个接触件放在各自绝缘腔中，接触底面与腔底 z34 对齐。其几何是接触簧片包络，不代表经过材料、接触力或耐久试验的合格簧片。前盖三孔与后插脚坐标一致，但孔宽/角度/间距/片厚均为**临时设计值**，不得当成中国 16 A 标准尺寸使用；须以有效标准和匹配的合格采购件更新。

## 电气连接与真实完成边界

PE 插脚→PEBus→PE 插套的几何并集为一个有效实体。该路径绕过 PCB 右侧，不经过继电器或计量开关。两个导电接口采用少量有意重叠来表示连接。它证明的是 CAD 连通，不证明焊接/铆接工艺、接地电阻或保护导体故障电流承受能力。PE 导体绝缘、固定、爬电与电气间隙仍需设计验证。

L/N 插脚与插套已加入分开的导体/绝缘护套路径，载体中有两个 D3.0 馈线通孔；端点对应电子板 J1/J2。护套外径2.8、导体直径1.3仅用于布线空间研究，**不是16 A线径选择**，也不代表导体载流量、弯曲半径、绝缘温度等级或端接的放行。导体在端子简化包络中有六处预期接入，实际进线孔与夹紧结构未确定。

已把保护组件真实分配到外壳内部，原先的保护断开空间已关闭。主通路按 L插脚→F_MAIN→TF1→保护后分支，分别供给J1与F_AUX→J5。N插脚分别连至J1/J5，负载N通过板端接口延续；PE独立连续。

- 左前口袋：Schurter OGN0031.8201开式保险丝座，主体包络25×9.6×11.5、引脚距22.5；配Littelfuse0216016.MXP 16A快断5×20陶瓷保险丝。独立壳内小托台与引脚通孔已建模
- 右前口袋：SensienceMICROTEMP G5系列热切断器，主体D4×14.7；110°C候选须根据真实接触件、壳体、热梯度重新确定。固定夹、热耦合与最终订货型号仍待确认
- 上部托台：Littelfuse0215001.MXEP 1A慢断轴向辅助保险丝，21.5×D5.5包络。长供货引脚按三维布线包络截短表示，端接与弯曲工艺未放行
- OGN无盖16A名义条件不能直接当成本封闭外壳内的持续16A能力；盖子会降低额定能力。全部保护器件仍须核算降额、短路分断、PSU浪涌I²t及相互配合

供应商来源与电气选择边界见电子目录的PROTECTION_AND_RF.md。器件外形按已核实包络简化建模，保险丝座内部金属夹、端接结构、热熔断器安装与陶瓷内部熔体不是供应商精确内部复原。

按键现有偏置推杆下端与电子板SW1(0,-29,z13.9)顶面匹配，正面按键仍为(0,-32)；导光柱延伸到LED1(0,31,z14.9)，正面出光点仍为(0,33,z55)。已做共同坐标包络检查；长推杆抗弯、行程/回弹/导向、光导耦合效率与安装公差尚未验证，不能把几何接触当成量产机构。

`ShutterSlider` 与 `ShutterGuide` 仅为联动防护门结构空间研究。弹簧、复位、双插脚同时触发、插拔运动、防单极插入及探针试验未实现或验证。不得宣称已有合格儿童保护门。

## 验证记录与放行门槛

脚本检查：所有 54 个机械形体有效且各自单实体；机械两两交集仅允许清单中明确列出的导电接合、保险丝端帽/引脚、线束分支绝缘拼接与天线馈线接口。对 72×68 PCB 与电子组提供的33个元件包络做共同坐标检查，六处端子接入已明确分类为预期界面。每次电子布局更改须重新运行整合审计。简化元件包络检查不等于供应商精确 3D 模型检查。

本包不包含：标准符合性、完整爬电/电气间隙矩阵、温升/故障试验、插拔力与接触电阻、模具可制造性、阻燃认证、跌落/冲击、额定负载切换与寿命、耐压、EMC、产品认证或通电许可。用户界面的“16 A”必须注明设计目标，不能替代产品合规铭牌。

下一步必须先选择标准化合格插接组件与匹配继电器/端子，完成线束及隔离、详细公差/热设计，再由合格人员评审低压样件和电气试验计划。
