# CARBENTRA CM-S16 · Rev B 机械工程开发包

**技术版本：CM-S16-EVT-B · 文件日期：2026-09-30**  
**状态：工程开发 / 制造与通电放行未通过。本文不声明最终几何审计、样机试验或产品认证通过。**

Rev B 采用原创 108 × 93 × 65 mm 名义外壳和一块 100 × 85 mm 集成主板，不是把四块实验模块简单叠放，也不是供应商产品的内部复原。目标为单个三孔、16 A 等级、220 VAC 智能插座。16 A 是设计目标，不能解释为本封闭外壳已经具备持续额定载流能力；无 10 A 或万能插孔兼容承诺。

## 1. 统一坐标、正反面极性

- 单位 mm；原点为名义后壳背面中心，z = 0；前表面 z = 65
- +Z 指向正面，+Y 向上，+X 在正面视图中向右
- **正面插座直接看孔，视线沿 −Z：L 右、N 左、PE 上**
- **背面插头直接看插脚，视线沿 +Z：L 左、N 右、PE 上**
- 后视图只改变观察方向，不能再次改变实际接线或交换世界坐标中的 L/N

| 导体 | 世界 X | 世界 Y | 长轴相对 +Y 的旋转（绕 +Z） |
|---|---:|---:|---:|
| PE | 0 | 11.1000000 | 0° |
| L | +8.2272413 | −4.7500000 | −30° |
| N | −8.2272413 | −4.7500000 | +30° |

L/N 坐标由 F = 9.5 的三角关系得到：X = ±F cos 30°，Y = −F sin 30°。中心横距 16.4544827；PE 至 L/N 中心水平线的高度差 15.85。Volex 图中的上侧 2.2 mm 虚线是供应商插头本体参考，不是本项目原点，不能再次叠加到上述坐标。

本项目只利用 Volex 2025 GB16C 图作**标准化配合接口的尺寸交叉检查**；外壳、布局、载体、导体和保护门为原创。该厂商产品的额定值、CCC 标识与符合性均不转移到 CARBENTRA。

名义元件顶面 z36.1 至载体底 z41 的高度差为 4.9。它是局部包装预算，不是可随意布线的整层空间，也不是电气安全距离。焊脚、F501 板底件、导体、真实连接器和支承都必须参加实际实体检查。

`RearFinish` 为薄装饰环时可能比名义外轮廓多出总宽/高 0.08 mm；最终最大外形必须从本次实体包围盒读取并在制造图上冻结，不能把 108 × 93 的名义值冒充测量值。

## 3. 主通路与保护器件不能混同

**主负载 L：后 L 插脚 → F_MAIN（电气 F601）→ TF1（电气 TF601）→ J201.1 → 板上分流器/继电器 → J102.1 → 前 L 插套。**  
N 经 J201.2、板上 N 通路和 J102.2 连续；PE 从后 PE 插脚沿独立导体直接至前 PE 插套，不经 PCB、继电器或保险丝。

| 部件 | 当前候选 / 位置意图 | 不代表什么 |
|---|---|---|
| F_MAIN / F601 | SCHURTER SHF **8020.5080**，16 A 快断，6.3 × 32 系列；名义外形 31.8 × Ø6.35 | 不是主动限流器；熔化 I²t 不是总开断 I²t 或下游可承受能量上界 |
| 主保险丝夹 | 两个 SCHURTER CQP **8040.0003**，独立 45 × 16 × 2 绝缘载板、铜集流片及机械压持 | 夹子的单件额定值不是自制座的封闭热容量或绝缘认证 |
| TF1 / TF601 | MICROTEMP G5 独立一次性热切断器；邻近接触热点，套管与压持件 | 候选 110°C 动作温度、订货后缀、热耦合和焊接工艺均未放行 |
| F501 | Littelfuse **0215001.MXEP**，板底独立 1 A 延时辅助电源支路保险丝 | 不承担 16 A 主负载保护；F501 前的引线仍依赖主保险丝保护 |

当前接触件已替换为原创双叶簧候选：名义叶厚0.4、未插入缝隙1.7；独立原生参数ContactGap用于1.8名义插入态和1.95最大参考脚厚态，名义每叶横向挠度分别0.05与0.125。它修正了早期2.2宽松空槽的几何问题，但材料牌号/硬态、镀层、成形半径、力学应力、接触力、温升及疲劳均未验证，不能当作合格簧片。

保险丝本体、夹子和引脚以核对过的名义/最大外形建模，仍不是供应商完整弹片、镀层、内部结构或公差 CAD。CQP 四孔排列、夹紧接触、铜集流片端接和可装配顺序须以实物与制造图确认。

## 4. 六条原创成形铜导体与独立 PE

当前 L/N 主回路使用六条自定义退火 **Cu-ETP 实心圆铜 Ø2.0 mm** 导体（截面积约 3.14 mm²），不是早期 2.5 mm² 柔性线方案。中心线使用真实圆弧，最小设计成形半径 R6；R6 是几何输入，未证明反复弯折寿命或工艺可行性。

| 路线 ID | 连接意图 |
|---|---|
| L_RAW | 后 L 插脚 → 主保险丝输入铜集流片 |
| N_RAW | 后 N 插脚 → J201.2 |
| L_FUSE_THERMAL | 主保险丝输出铜集流片 → TF1 一端 |
| L_PROTECTED | TF1 另一端 → J201.1 |
| L_OUTPUT | J102.1 → 前 L 插套引出片 |
| N_OUTPUT | J102.2 → 前 N 插套 |

导体保持于专用刚性绝缘载体内：名义外径 4.4、内径 2.4、径向壁厚 1.0；路由周围保留额外 0.25 径向安装预算。端子入口名义 z20.6，模型保留 ±1.0 的入口高度不确定性和约 8 mm 直段接入。**端子是否允许这种成形实心端头、端头处理、夹紧力、防松与拉拔试验均未确认。** 包络重叠仅表示预期接入，不能证明真实夹口有接触。

后L插脚内部宽片至z5；后N宽片至z3.2，中央圆柱端头至z6.5；L输入铜杆接头中心z5.7。该降低后端端接的方案与PCB局部改线共同接受几何审查，外部插脚伸出21/18的接口尺寸不变。

PE 是另一条独立铜通路及绝缘通道。CAD 并集连通不证明接地电阻、接合强度或故障电流承受能力。所有铜材料、镀层、连接工艺及故障保护配合须由专业人员审查。

## 5. 保护门、热耦合与装配固定

- 保护门有共同滑块、两个独立压下的锁爪、锁爪弹簧和回位弹簧；名义闭合行程 0，打开行程 12.5。现有机构用于数字运动研究，不宣称已通过单极插入、防误触或寿命试验
- 应同时验证闭合遮挡、双脚开启、单脚阻挡、释放后复位、弹簧压并、脱扣和塑料蠕变。只在终点无干涉不能证明全行程无卡滞
- 传感头采用接触热点旁的电绝缘导热路径，候选 0.5 mm KERATHERM 86/60 片。材料击穿试样数据不能当作整机加强绝缘；边缘爬电、压缩、防切穿、防移位及真实温度滞后均开放
- L/N 极性修正后，当前传感头中心为(+10.8272413, −4.75)，导热片中心为(+8.2272413, −4.75)；传感头绕X翻转180°，热耦合背面名义z43.5。传感头、导热片、TF1 与 L 插套仍必须以本次组合实体检查
- PCB 固定、载体承台与前盖压持、主保险丝夹载板/压持件、热切断器压持、导体载体、按钮导向均是可检查对象；当前螺钉以名义螺纹大径包络表示，导孔接合长度约3–4 mm；实际螺钉系列、导孔尺寸公差、扭矩、装配工具路径、维修安全及长期保持力仍未冻结

## 射频线缆与连接器装配边界

所选天线带100 mm同轴，当前名义引线路由约56 mm；其余约44 mm已分配到有保持导向的服务环路预留区。非实体环形包络RFServiceSlackEnvelope中心(23,35.8)，内/外半径6.1/7.95，z46.5–50.5；前盖在x16/30、y35.8有两个一体导向卡扣。该预留按约7 mm环路半径及R≥6 mm假设布置，代表空间分配，不是精确电缆中心线路由。制造商允许弯曲半径、实际装配余量、保持力及连接器应力释放仍需资格验证。该参考对象默认隐藏、非物理零件，不计入71件物理部件或质量。实际配对RF连接器与传感头排针外壳目前是标识过的包络，不能作为精确配合或保持力证明。

## 6. 包络与真实性等级

| 证据等级 | 本包能支持的判断 | 不能外推到 |
|---|---|---|
| 参数与原创形体 | 当前设计输入、空间安排、名义运动关系 | 厂商精确 CAD、制造公差或合格标准接口 |
| 同坐标名义/最大器件包络 | 明显穿透和空间冲突；必须包含板底器件与焊脚 | 实际卡扣、引脚弯曲、夹口、供应商装配公差 |
| 本次 BRep / 扫掠检查 | 所检查对象和状态中的几何干涉或连通 | 电气间隙、爬电、接触力、耐压、热安全或认证 |
| 未来专业测量/试验 | 仅对应完成的试验条件与样品 | 未测量的长期可靠性或其他使用条件 |

不提供实测质量、重心、墙插静力矩、温升或插拔力。早期封装研究中的质量和力矩区间是敏感性假设，不能成为产品规格。墙面保持需包含外接插头、电缆垂重及牵拉工况。

## 7. 放行流程

完整门槛见 [TOLERANCE_AND_RELEASE_GATES.md](TOLERANCE_AND_RELEASE_GATES.md)。至少先完成：

1. 冻结同版本 PCB / 机械 / 物料 / 坐标；重新生成所有导体清单、装配和审计
2. 用正式 GB 1002-2024 图纸与适用量规确认正反面接口；完成完整公差链和配对件极限状态
3. 完成主回路、PE、保险丝/TF1、导体端接、接触力与绝缘结构的专业评审
4. 先做不通市电的装配/运动样件，测保持、全行程、端接、机械耐久与材料行为
5. 在合格设施按批准计划进行接地、绝缘、温升、故障、保护配合、EMC及认证相关试验

**没有任何几何通过记录可单独解除通电与制造放行限制。**
