## 2. 必须闭合的公差链

1. **配合接口**：标准最大/最小插脚、孔与插套位置度、脚角/翘曲、袖套、壳体拔模、插入倾斜及保护门凸轮；在同一基准方案中作极限状态检查，不能仅对称放大孔
2. **PCB与端接**：板外形/安装孔/板厚 → 支柱 → 插接件安装高度/焊接姿态 → 夹口 → 成形导体回弹/裸端 → 导体载体 → 铜接触件。必须包含孔位置误差和装配可达性
3. **闭壳与保持**：后壳承台 → 插接载体 → 压紧凸台 → 前盖/螺柱。当前螺钉为名义螺纹大径包络，导孔接合约3–4mm，实际螺钉系列/导孔公差/扭矩未冻结。理想面贴合不能同时承担定位、预压及零干涉；需明确间隙、预紧窗口、允许压缩和热老化后的保持
4. **热耦合与绝缘**：L接触片/TF1 → 绝缘片压缩 → 传感头 → 压持/防移位。采用最不利压缩和边缘爬电路径，并验证元件面不会侵入触点
5. **运动和回位**：锁爪/导槽/滑块/弹簧尺寸、摩擦和倾斜；同时验证完全闭合、单脚触发、两脚开启、最大行程、回位再锁定及弹簧压并

6. **RF与传感器线束**：所选100mm同轴的约56mm引线路径之外，约44mm已分配到有前盖一体卡扣保持导向的服务环路预留区；非实体环形参考包络位于(23,35.8)、内外半径6.1/7.95、z46.5–50.5，默认隐藏且不计入71件物理部件。R≥6mm和约7mm环路半径仍为布置假设；精确电缆路径、供应商弯曲规则、装配余量、保持力和连接器应力释放待验证。RF配对连接器和传感头排针外壳仍是包络，实际装配尺寸与端接均需核实

## 4. 已识别的版本差异与当前处理

- `PACKAGING_STUDY.md` 的PCB板底z11是早期研究；本文用当前z11.5
- 已修正：删除旧通用 `blade_projection:20`；图、参数和当前特征用PE21、L/N18
- 已修正：`harness`已与当前六条Ø2实心铜路线一致；早期2.5mm²柔性线方案仅保留于历史研究，当前来源是 `power_links.py`
- 旧导体清单曾残留(±14,−7)坐标与旧主保险丝端点名称；交付必须使用最终导出器重新生成的清单，不复用旧审计证据
- 已修正：热接口元数据为正X侧，头中心(+10.8272413,−4.75)，导热片中心(+8.2272413,−4.75)，头绕X轴180°；传感头导出与组合实体的本次最终审计仍另行提供
- 已修正：保护门文字与输入均为12.5打开行程；最终运动审计必须绑定实际参数
- 主保险丝使用F_MAIN/F601、热切断器用TF1/TF601、1A板底辅助保险丝用F501；旧Rev A 216/OGN组合不能混入Rev B当前配置

本清单指出的差异若被后续修正，应以最终冻结快照与重建记录关闭；不需要保留一个已经修正的错误作为产品要求。

## 当前几何审计的证据边界

[绝缘域3D报告](../insulation_domain_report.md)纳入主板实际焊盘、走线、过孔保守包络和GND_ISO填充区，以及四个机壳螺钉。名义最小裸露主侧金属至主板隔离侧铜为8.5166mm，只达到项目8.4mm几何筛查目标，名义余量约0.1166mm；它不是标准电气间隙、公差裕量或安全放行。隔离传感头仍保留独立0.5mm固体绝缘界面；1mm导体载体树脂、螺钉孔/塑料路径及可触及性都须资格验证。
